Eight ways to read the same four boxes

Accuracy, AUC, Recall, Precision, F1, Kappa and MCC are not seven separate measurements. Six of them are arithmetic on one 2×2 table, and they disagree only because each one reads a different part of it. Pick a metric below and the boxes it actually uses light up. The seven models exist so you have seven different tables to read.

The case. A bank decides who gets a loan. The test set is 1000 real applicants: 200 went on to default, 800 repaid. Every model saw those same 1000 people. The only thing that differs between models is how the four boxes fill up.
